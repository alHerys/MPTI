# Sumber Riset

Folder ini disediakan untuk laporan riset asli (latar belakang). Pada sesi build ini folder kosong: laporan riset tidak disertakan, sehingga dokumen proyek hanya memakai rujukan yang ditandai *"dikutip dari laporan riset; verifikasi sebelum dipresentasikan"*.

Baris **SteadyMouse** pada tabel prior-art laporan riset sengaja tidak disalin (kontaminasi copy-paste yang tidak relevan).
